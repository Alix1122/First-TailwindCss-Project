# First-TailwindCss-Project

My first project built with **Tailwind CSS v4** and the **Tailwind CLI**.  
A modern, responsive landing page built with HTML and CSS only — no JavaScript framework.

![Site preview]()

---

## ✨ Features

- 🎨 Modern design with a **hero section**, a **testimonials section** and a **footer**
- 📱 **Fully responsive** — mobile, tablet and desktop
- ⚡ **Tailwind CSS v4** — CSS-first configuration via `@theme`
- 🛠️ **Tailwind CLI** — automatic build with `--watch`
- 🧩 No external JavaScript dependency

---

## 📂 Project structure

First-TailwindCss-Project/
├── src/
│ ├── img/ # Site images
│ ├── index.html # Main page
│ ├── input.css # Source CSS (with @import "tailwindcss")
│ ├── output.css # Compiled CSS (generated by the CLI)
│ └── script.js # Optional scripts
├── package.json
├── package-lock.json
└── README.md
